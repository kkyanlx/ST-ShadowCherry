# ✦ Shadow Cherry · Atmosphere

*影色のさくらんぼ · fog, ash & porcelain rose*

Атмосфера для темы **Shadow Cherry** в [SillyTavern](https://github.com/SillyTavern/SillyTavern): медленно плывущий туман и пылинки в воздухе.
Сама тема живёт в пресете [Moonlit Echoes](https://github.com/RivelleDays/SillyTavern-MoonlitEchoesTheme), а это расширение отвечает только за погоду.

by **ewwn1h** ♡

---

## Установка

Extensions → Install extension → вставьте ссылку и перезагрузите страницу:

```text
https://github.com/kkyanlx/ST-ShadowCherry
```

## Настройки

**Extensions → ✦ Shadow Cherry**

| | |
|---|---|
| Туман · плотность | дымка между фоном и чатом |
| Туман · поверх чата | та же дымка над перепиской, мягче, текст читается |
| Пылинки · количество | крошечные частицы, дрейфуют вверх |

- Если в SillyTavern или в системе включено «меньше анимаций», туман и пылинки замирают.
- Когда вкладка свёрнута, анимация стоит на паузе.
- На телефоне частиц вдвое меньше, отрисовка ограничена 30 кадрами в секунду.
- Туман двигается только через transform, поэтому не нагружает телефон.

## Обновление

Extensions → Manage extensions → обновить **✦ Shadow Cherry**.

## English

Atmosphere for the Shadow Cherry theme: slowly drifting fog and floating dust, each with its own switch
and slider under Extensions → ✦ Shadow Cherry. Works with any theme, made for Shadow Cherry on Moonlit Echoes.
Respects “reduced motion”, pauses in background tabs, uses half the particles on phones.
